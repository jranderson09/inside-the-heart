# inside-the-heart
Interactive, bilingual (English/Spanish) guide to heart anatomy, ECG rhythms, and cardiology, with a review paper on compression therapy for venous disease.

Inside the Heart

An interactive, bilingual (English/Spanish) guide to how the heart works, created by Jacob Anderson, an aspiring cardiovascular surgeon.


What's inside
Beating heart and heart-rate slider: Adjust the rate from 40 to 180 bpm and see how it compares with resting and exercise ranges.
Clickable anatomy diagram: Tap any chamber, valve, or vessel to learn what it does and why surgeons care about it, including the coronary artery known as the LAD.
ECG Lab: A live scrolling ECG trace with four rhythms (normal sinus rhythm, bradycardia, tachycardia, and atrial fibrillation) and a short explanation of each.
Quiz: Six multiple-choice questions with an explanation after each answer and a final score.
Surgeon's Notebook: Reflections on shadowing a cardiac surgeon at REX Hospital (50+ hours) and volunteering at Compression Care Center (300+ hours).
Review paper: A short literature review on compression therapy for chronic venous disease, with a full reference list. It is a review of existing research, not original research.
English/Spanish toggle: Switch languages from the top navigation bar. The review paper is in English only.
Running it locally

There is nothing to install. Download index.html and open it in any modern web browser.

The site is a single HTML file with its own CSS and JavaScript, and it does not use external libraries or a backend.
